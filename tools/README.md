# tools/

`tectonic` — the self-contained XeLaTeX engine (v0.17.0, MIT-licensed),
fetched from the official tectonic releases
(https://github.com/tectonic-typesetting/tectonic/releases). Bundled so that
`source/build.sh` works offline. `source/pipeline/` discovers it here first;
delete this folder to have the build fetch it on demand instead.
