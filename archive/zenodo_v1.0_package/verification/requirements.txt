# Qubitick verification suite — Python requirements
#
# The suite is PURE PYTHON 3 STANDARD LIBRARY (Python >= 3.8):
# integers, fractions.Fraction, complex-over-Fraction, truncated power series
# over Fraction, and exact radical/algebraic rings implemented in the suite's
# own helper modules (checks/hcommon.py, checks/qmath.py, checks/q5.py, ...).
#
# No third-party packages are required — in particular, no sympy: every
# algebraic number field, prime-log ring and integer certificate used by the
# checkers is exact and self-contained, and no assertion uses floating point.
#
# This file is intentionally comment-only, so that
#     pip install -r requirements.txt
# is a safe no-op that documents the dependency-free contract.
